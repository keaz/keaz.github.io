# Kasun Ranasinghe Portfolio

Personal portfolio site built with React, TypeScript, and Vite.

## Stack

- React 19
- Vite 8
- TypeScript 6
- ESLint 9 flat config
- pnpm

## Requirements

- Node.js 20.19 or newer
- pnpm 10

## Development

```bash
pnpm install
pnpm dev
```

## Quality Checks

```bash
pnpm lint
pnpm build
```

## Deployment

```bash
pnpm deploy
```

The site is configured for GitHub Pages and builds into the `build/` directory.
